一个持续更新的精选资源列表，涵盖算法竞赛、数学、编程语言、计算机科学和在线工具。仿照 GitHub 上的 awesome 系列，按分类整理。

## 1 算法竞赛与 OJ

- [Codeforces](https://codeforces.com/) — 全球最大的算法竞赛平台之一
- [AtCoder](https://atcoder.jp/) — 日本竞赛平台，题目质量极高
- [Luogu 洛谷](https://www.luogu.com.cn/) — 国内最大的 OJ 与算法社区
- [OI Wiki](https://oi-wiki.org/) — 竞赛知识百科，覆盖几乎所有算法知识点
- [USACO Guide](https://usaco.guide/) — 从入门到 IOI 的系统学习路径
- [CP-Algorithms](https://cp-algorithms.com/) — 竞赛算法大全（原 emaxx 俄文站英译）
- [Codeforces EDU](https://codeforces.com/edu/courses) — CF 官方教程，含二分、线段树、Suffix Array 等
- [CSES Problem Set](https://cses.fi/problemset/) — 经典的分类练习题库
- [VNOI Wiki](https://vnoi.info/wiki/) — 越南 OI 社区的算法百科
- [Algorithms for Competitive Programming (PDF)](https://github.com/pllk/cphb) — 《Competitive Programmer's Handbook》免费电子书

### 在线评测与虚拟比赛

- [Virtual Judge](https://vjudge.net/) — 聚合多家 OJ 的虚拟评测平台
- [Codeforces Gym](https://codeforces.com/gyms) — 大量区域赛和训练赛
- [Kattis](https://open.kattis.com/) — 开放式算法题库
- [Library Checker](https://judge.yosupo.jp/) — 验证算法模板正确性的专用 OJ

## 2 数学

### 离散数学与抽象代数

- [近世代数 韩士安 第二版](https://book.douban.com/subject/30448958/) — 中文经典群论教材
- [Abstract Algebra (Dummit & Foote)](https://book.douban.com/subject/1592931/) — 英文抽象代数圣经级教材
- [Visual Group Theory (Nathan Carter)](https://book.douban.com/subject/4731283/) — 用可视化方式讲解群论
- [Group Explorer](https://nathancarter.github.io/group-explorer/) — 群论可视化软件
- [AATA: Abstract Algebra Theory and Applications](http://abstract.ups.edu/) — 免费在线抽象代数教材

### 范畴论

- [Category Theory for Programmers (Bartosz Milewski)](https://github.com/hmemcpy/milewski-ctfp-pdf) — 为程序员写的范畴论经典，含免费 PDF 与视频
- [nLab](https://ncatlab.org/) — 范畴论与数学物理的协作百科
- [The Catsters (YouTube)](https://www.youtube.com/user/TheCatsters) — 用画图方式讲范畴论的经典视频系列
- [Seven Sketches in Compositionality](https://arxiv.org/abs/1803.05316) — 应用范畴论入门

### 数学工具

- [GeoGebra](https://www.geogebra.org/) — 在线数学绘图/几何工具
- [Desmos](https://www.desmos.com/calculator) — 在线函数绘图
- [Wolfram Alpha](https://www.wolframalpha.com/) — 符号计算与数学查询
- [OEIS (整数数列百科)](https://oeis.org/) — 输入数列前几项，推断数学规律
- [SymPy](https://www.sympy.org/) — Python 符号计算库
- [3Blue1Brown](https://www.3blue1brown.com/) — 数学直觉可视化视频

## 3 Haskell 与函数式编程

### Haskell 学习

- [Learn You a Haskell for Great Good! (LYAH)](http://learnyouahaskell.com/) — 最经典的 Haskell 入门书
- [Haskell Programming from First Principles](https://haskellbook.com/) — Haskell 黄皮书，系统深入
- [Real World Haskell](http://book.realworldhaskell.org/) — 实战导向的 Haskell 教材
- [Hoogle](https://hoogle.haskell.org/) — Haskell API 搜索引擎
- [Hackage](https://hackage.haskell.org/) — Haskell 包仓库
- [What I Wish I Knew When Learning Haskell](https://dev.stephendiehl.com/hask/) — 一个综合性的 Haskell 参考
- [Ninety-Nine Haskell Problems](https://ninetynine.haskell.chungyc.org/) — 99 道 Haskell 练习题
- [Haskell Wiki](https://wiki.haskell.org/) — Haskell 社区维基

### 函数式编程通用

- [Functional Programming HOWTO (Python 官方)](https://docs.python.org/3/howto/functional.html) — Python 官方函数式编程指南
- [Mostly Adequate Guide to FP (JS)](https://mostly-adequate.gitbook.io/mostly-adequate-guide/) — JavaScript 函数式编程入门
- [Professor Frisby's Mostly Adequate Guide](https://github.com/MostlyAdequate/mostly-adequate-guide) — 同上，GitHub 版本

### 函数式编程库

- [fp-ts](https://github.com/gcanti/fp-ts) — TypeScript 函数式编程库（HKT、Monad、ADT）
- [effect-ts](https://effect.website/) — TypeScript 的 Effect 系统
- [Ramda](https://ramdajs.com/) — JavaScript 实用函数式库
- [lodash/fp](https://github.com/lodash/lodash/wiki/FP-Guide) — Lodash 的函数式风格
- [returns (Python)](https://github.com/dry-python/returns) — Python 的 Result/Either/Maybe 类型
- [toolz (Python)](https://github.com/pytoolz/toolz) — Python 函数式工具库（柯里化、管道）
- [PyMonad](https://github.com/jasondelaat/pymonad) — 纯 Haskell 风格的 Python Monad 库
